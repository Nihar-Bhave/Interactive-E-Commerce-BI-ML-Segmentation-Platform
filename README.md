# Interactive-E-Commerce-BI-ML-Segmentation-Platform
An interactive Business Intelligence and Machine Learning web application built using Python and Streamlit to analyze e-commerce business performance and customer purchasing behavior.

The platform integrates data processing, SQL-based ETL workflows, business intelligence metrics, and unsupervised machine learning to provide insights into revenue performance, order fulfillment, inventory status, and customer segmentation.

**Key Features:**
- Developed an interactive Streamlit dashboard to monitor revenue metrics, fulfillment health, and inventory status.
- Implemented an automated SQL-to-Pandas ETL pipeline to extract, transform, and process data from multiple relational tables.
- Applied K-Means Clustering with StandardScaler to segment customers based on Customer Lifetime Value (CLV) and purchase frequency.
- Integrated SQLite for structured data storage and management.
- Combined business intelligence analytics with machine learning to support customer behavior analysis.

**Technologies Used:** Python, Streamlit, Scikit-Learn, SQLite, Pandas, SQL, K-Means Clustering.

**Objective:** To build a data-driven analytics platform that combines business intelligence and machine learning to help understand customer behavior and e-commerce business performance.
